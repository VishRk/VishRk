### 🚀 Featured Projects

| Project | Stack | Highlights |
|---|---|---|
| **Tool-Calling Agent Loop** — From Raw API to Production Patterns | Anthropic Messages API (raw HTTPS), FastAPI, Python | Multi-tool agent loop built directly on the Messages API with `tool_use`/`tool_result` correlation, iteration/token-budget guards, and concurrent tool execution via `ThreadPoolExecutor`. Measured tool-selection accuracy on a 20-query eval set across 4 tools. Diagnosed a silent retrieval-quality bug from asymmetric query/passage embedding prefixes (0-of-5 top-result overlap, zero surfaced errors). Manually evaluated retrieved chunks (not just similarity scores) across 10 queries and traced misses to real failure modes. |
| **Agentic AI Configuration Platform** *(Adobe, internal)* | React/TypeScript SPA → FastAPI orchestration → custom MCP server | Converts natural-language requests into validated, risk-scored contact-center configuration changes. Agentic tool-calling loop on Azure OpenAI GPT-4o with ~80 typed function-calling tools, SSE streaming, layered guardrails (prompt-injection detection, PII redaction, schema/allow-list validation), and 160+ pytest tests. |
